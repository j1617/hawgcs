403 错误说明

403 是因为 Gitee 对匿名请求有频率限制，高频使用会触发。

解决方法：申请 Gitee Personal Access Token

  1. 打开 gitee.com/profile/personal_access_tokens
  2. 点击「创建令牌」，描述随意，如 HAWGCS
  3. 权限只勾选 「projects」（项目相关）
  4. 创建后复制 Token（只显示一次）
  5. HA → 设置 → 设备与服务 → HAWGCS → 配置
  6. 在 Token 栏粘贴，保存

Token 仅用于突破 Gitee API 频率限制，不影响仓库公开属性。
